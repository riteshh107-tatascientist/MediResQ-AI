# Empathy Map — Hospital Supply Chain / Pharmacy Manager (persona hypothesis)
*Unvalidated hypothesis built from the problem domain; to be validated through the interviews in `DESIGN_THINKING.md`.*

| Quadrant | Hypothesised content |
|---|---|
| **Thinks** | "If a life-saving drug runs out, it is my responsibility." "Is there stock in another hospital I can borrow from?" "Will this batch expire before we use it?" |
| **Feels** | Anxiety about stockouts; frustration with late suppliers; pressure from audits and wastage; overwhelmed by spreadsheets |
| **Says** | "The shipment is delayed again." "I only found out when the ward called." "Can you transfer 200 vials today?" |
| **Does** | Checks stock registers and spreadsheets; phones suppliers and peer hospitals; raises emergency purchases; escalates to supervisors |
| **Sees** | Stock figures that differ by location; expiry labels; delayed delivery notes; shortage complaints |
| **Hears** | Clinicians asking for availability; suppliers promising dates; managers asking for justification |
| **Pains** | Late visibility; siloed inventory; manual transfers; wastage from expired stock; no audit trail for decisions |
| **Gains** | Early warning with reasons; cheapest feasible recovery; one place to approve and document decisions; fewer emergency buys |
