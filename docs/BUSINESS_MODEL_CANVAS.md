# Business Model Canvas — MediResQ AI
*All entries are proposed **business hypotheses**. No customers, pilots, partnerships or revenue exist.*

| Block | Hypothesis |
|---|---|
| **1. Customer segments** | Hospitals; hospital networks/groups; healthcare warehouses; public healthcare procurement organisations; pharmaceutical distributors |
| **2. Value propositions** | Early, explained stockout warning; expiry/wastage reduction via FEFO and safe transfers; cheapest feasible recovery plan; what-if resilience testing; audit-ready human approval |
| **3. Channels** | Direct pilots with health departments/hospital groups; healthcare IT integrators; SAP ecosystem marketplaces (future); hackathon/academic showcases |
| **4. Customer relationships** | Co-designed pilots; onboarding + training; dedicated customer success; user community for threshold tuning |
| **5. Revenue streams** | SaaS subscription per facility/medicine line; implementation & data-integration fees; premium analytics/simulation tier; support contracts |
| **6. Key resources** | Forecasting + optimisation IP; data engineers/data scientists; domain advisors (pharmacy, procurement); secure cloud hosting; integration connectors |
| **7. Key activities** | Product development; data onboarding and validation; model monitoring; integration with ERP/WMS; support and training |
| **8. Key partnerships** | *Potential:* hospital networks for pilots, pharma distributors, ERP/SAP integrators, cloud providers, academic/health-policy bodies — none exist today |
| **9. Cost structure** | Engineering, cloud hosting, integration work, security/compliance, customer support, sales |

Validation plan: customer-discovery interviews → paid-pilot willingness → measure stockout/wastage baselines before any ROI claim.
